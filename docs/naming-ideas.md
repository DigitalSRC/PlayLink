# Naming brainstorm

Why this exists: while researching competitors for the landing page, we found Sony ran an official
PlayStation product line called **"PlayLink"** (2017–2019ish party games controlled via a phone
companion app — *That's You*, *Hidden Agenda*, a *Battleship* app still listed on the App Store). A
"connects players to play games together via a companion app" product under the exact same name is
close enough that it's worth having backup name candidates ready, even though no decision to
rebrand has been made.

**Nothing on this list has been trademark-checked.** This is raw brainstorm output, not a cleared
shortlist — a few are flagged below as known-taken because they were recognized, but absence of a
flag does not mean a name is safe. Before getting attached to one, it needs a real search (USPTO
TESS/TMsearch at minimum, ideally an actual trademark attorney) the same way PlayLink itself should
have gotten before any real investment went into the brand.

## Closest to PlayLink's existing rhythm (easiest transition if it comes to that)

- **TableLink** — same two-syllable-plus-"Link" cadence as PlayLink; "Link" alone isn't Sony's
  mark, only the "PlayLink" combination is
- **PodLink**
- **MeetLink**
- **LocalLink**

## Leans on "Pod" (already existing Commander/EDH vocabulary)

- **PodUp**
- **PodFinder** — very descriptive/literal, which cuts both ways: clear to users, harder to
  actually trademark because descriptive marks get weaker legal protection
- **OpenPod**
- **PodNear**
- **FindAPod**
- **PodSpot**

## Leans on "Table"

- **FullTable**
- **TableRadius**
- **TableFinder**
- **TableCircle**
- **NearTable**
- ~~OpenTable~~ — **taken**, this is the well-known restaurant reservation company, don't use

## Leans on proximity/"near you" (very literal, safe-feeling, less distinctive)

- **NearPlay**
- **PlayNearby**
- **NearMyTable**
- **CloseTable**
- **PlayNear**

## Casual gaming vernacular

- **TapIn** — "tap in" as in show up/join, modern and short
- **PullUp** — "pull up" as in show up somewhere
- **LinkUp** — keeps a "Link" pun without being "PlayLink"
- **ShowUp**

## Abstract / invented brandables

- **Podly**
- **Tablemate** / **Tablemates** — unverified, evokes companionship
- **Playfield**
- **Playspot**
- **Bracketly** — nods to the Commander bracket system specifically
- **Nearcade** — near + arcade; risk is it reads as video-game arcade, not tabletop

## Community/gathering themed

- **Podmates**
- **GroupUp**
- **SquadUp** — fairly generic gaming term already used by several other apps/services, weak
  distinctiveness even if not directly "taken"
- ~~Playmates~~ — **taken**, Playmates Toys (and the Playboy "Playmate" mark) — avoid
- ~~GameLink~~ — **likely taken**, there's a long-standing adult-entertainment retailer using this
  name — avoid
- ~~CircleUp~~ — **taken**, an existing fintech/crowdfunding platform — avoid

## My ideas

- **PlayBy** — "Players By me!"

## Current pick, if you want one opinion

**TableLink** — closest to PlayLink's existing brand equity and rhythm (least jarring if a rebrand
actually happens), and "table" is arguably even more specific to tabletop gaming than "play" was.

## Next step when you're ready

Pick 2-3 favorites and run the same kind of research pass that turned up the Sony conflict on
PlayLink — general web search plus whatever can be pulled from USPTO's public trademark search —
before any real decision or spend goes toward one.
